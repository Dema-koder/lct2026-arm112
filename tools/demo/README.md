# Демо-данные для показа

Одна группа из 10 обучающихся, 6 занятий режима «Заполнение карточки» по 3 билета одной темы (пожары, медпомощь, правонарушения, человек в опасности, городское хозяйство, газ — зачёт с проверкой и публикацией). Всё идёт через настоящий API: оценку считает оценщик, разборы пишет модель, преподаватель проверяет часть работ.

1. Поднять **чистый** стенд с моделью и без демо-аналитики (`ARM112_SEED_ANALYTICS_DEMO_ENABLED=false`, `ARM112_LLM_URL`).
2. `python tools/demo/demo_data.py http://localhost:8080/api/v1` — около 40 минут; учётные записи `op01`…`op10`, пароль `demo2026`.
3. Дождаться пустой очереди разборов: `select count(*) from job where state in ('READY','RUNNING')` = 0 (≈ 50 с на разбор).
4. `psql … < tools/demo/backdate.sql` — разнести занятия по прошедшим неделям.
5. Администратор → «Система» → резервная копия (или `POST /api/v1/admin/backups`); архив и `.sha256` — в каталоге копий.

Перенос: та же версия приложения на сервере → архив и `.sha256` в `/data/backups` контейнера backend (`docker cp`) → восстановление в кабинете администратора (слово `RESTORE`) → сменить пароли демо-учёток.
