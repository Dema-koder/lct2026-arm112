# Справочник улиц: чем наполнен и как заменить на ГАР

Справочник отвечает на один вопрос: **существует ли улица с таким названием**. От ответа зависит, чем считать расхождение с эталоном — опечаткой (−40) или неверным адресом (−60). Разница существенная: при опечатке ошибка всплывёт, при неверной существующей улице расчёт уедет по действительному адресу в другой район.

Подробности правила — в [ASSESSMENT_AND_SCENARIOS.md §3.2](ASSESSMENT_AND_SCENARIOS.md), код — `AddressMatcher` и `AddressReferenceService`.

---

## 1. Что сейчас в поставке

| | |
|---|---|
| Источник | OpenStreetMap, выгрузка через Overpass API |
| Область | Москва, `admin_level=4` |
| Снято | 2026-09-23 |
| Названий | 5630 (после нормализации 5343 различимых) |
| Размер | 242 КБ |
| Лицензия | **ODbL 1.0** |

Плюс 48 названий из библиотеки сценариев, которых в выгрузке нет. Справочник — объединение обоих источников, поэтому расширение внешнего списка ничего не ломает.

### ⚠️ Лицензия требует решения

OSM распространяется под ODbL, у которой есть требования к производным базам: атрибуция и share-alike. Список названий без геометрии — пограничный случай, и решать его должны юристы заказчика, а не разработка.

**Рекомендация: заменить на ГАР до поставки.** ГАР — официальный государственный реестр ФНС, открытые данные без ограничений на распространение. Для государственной системы это единственный однозначно чистый вариант.

Атрибуция сейчас лежит в самом файле `seed/streets.json` в полях `source`, `licence` и `attribution`, и приложение печатает её в журнал при загрузке.

## 2. Почему ГАР не выгружен сразу

Официальные источники недоступны из среды разработки:

| Адрес | Ответ |
|---|---|
| `fias.nalog.ru` | нет соединения |
| `gar.nalog.ru` | нет соединения |
| `fias.nalog.ru/WebServices/Public/GetLastDownloadFileInfo` | нет соединения |
| `fias-file.nalog.ru/downloads/` | 403 |

Похоже на ограничение по региону источника. Кроме того, полный архив ГАР — около 35 ГБ, и качать его в среде разработки нецелесообразно в любом случае.

---

## 3. Как собрать справочник из ГАР

Делается один раз на машине с доступом, результат кладётся в поставку.

```bash
# 1. Узнать ссылку на актуальный архив
curl https://fias.nalog.ru/WebServices/Public/GetLastDownloadFileInfo

# 2. Скачать полный архив (около 35 ГБ)
curl -O https://fias-file.nalog.ru/downloads/<дата>/gar_xml.zip

# 3. Распаковать только нужные регионы: 77 — Москва, 50 — Московская область
unzip -j gar_xml.zip '77/AS_ADDR_OBJ_*.XML' '50/AS_ADDR_OBJ_*.XML' -d ./gar

# 4. Собрать справочник
python tools/build-streets-from-gar.py ./gar src/main/resources/seed/streets.json --regions 77 50
```

Скрипт [tools/build-streets-from-gar.py](../../tools/build-streets-from-gar.py) отбирает объекты уровня 7 — элементы улично-дорожной сети — и только действующие и актуальные записи.

**Почему важна актуальность.** Неактуальные записи в ГАР — это переименованные и упразднённые объекты. Если включить их в справочник, старое название улицы будет засчитано как верное, и обучающийся не узнает об ошибке, из-за которой в бою расчёт уехал бы не туда.

**Про Московскую область.** В библиотеке сценариев есть адреса за пределами Москвы — Балашиха, Железнодорожный, Жуковка. Если такие вводные останутся, регион 50 нужен тоже.

## 4. Формат файла

Приложение принимает два вида, но предпочтителен второй — сведения о происхождении должны ехать вместе с данными:

```json
["улица Берзарина", "Цюрупы", "..."]
```

```json
{
  "source": "ГАР (ФИАС), ФНС России",
  "licence": "Открытые данные",
  "attribution": "Государственный адресный реестр, https://fias.nalog.ru",
  "area": "регионы 77, 50",
  "streets": ["ул Берзарина", "..."]
}
```

Тип улицы в названии не мешает: `TextUtil.normalize` отбрасывает «улица», «проспект», «переулок» и прочие перед сравнением. Поэтому «ул Берзарина», «улица Берзарина» и «Берзарина» — одно и то же.

## 5. Что даёт замена на ГАР

| | OSM сейчас | ГАР |
|---|---|---|
| Полнота по Москве | высокая, но без ведомственных и внутриквартальных проездов | полная по реестру |
| Область | только Москва | любые регионы |
| Актуальность | зависит от правок сообщества | официальная, с датой |
| Переименования | старые названия могут оставаться | помечены неактуальными и отбрасываются |
| Лицензия | ODbL, требует решения | открытые данные |

На качество оценки замена повлияет умеренно: 15 эталонных прогонов совпали и с библиотечным справочником из 82 названий, и с расширенным до 5391. Ценность ГАР не в баллах, а в том, что обучающийся, набравший существующую, но неверную улицу, получит верное замечание независимо от того, попала она в выгрузку сообщества или нет.

## 6. Проверка после замены

```bash
mvn verify -Dtest='!CohortSimulator' -Dgolden.strict=true -Dgolden.stage=streets-gar
```

Смотреть на два прогона:

- **R02 «Опечатка в названии улицы»** — вводится «Берзорина» вместо «Берзарина». Должен остаться −40. Если станет −60, значит в справочник попало несуществующее название.
- **R12 «Другая реальная улица»** — «Белозерская» вместо «Беломорской», обе существуют. Должен остаться −60. Если станет −40, значит одной из улиц в справочнике нет.

Эти два прогона и есть проверка справочника: они различают ровно те два случая, ради которых он заведён.
