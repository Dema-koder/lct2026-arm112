# 2026-09-28 — окно генерации сценариев и пометка новых

**Ветка:** `feat/generate-dialog`
**Коммит:** `—` (заполнить после коммита)
**Суть:** преподаватель генерирует сценарии из отдельного окна с выбором категории и видит, какие сценарии новые и ждут проверки.

## Что сделано

### Фронтенд

- «✦ Сгенерировать…» открывает окно: категории плитками с числом сценариев в библиотеке (меньше 10 — «мало»), количество, сложность. Категория выбирается в окне, фильтр списка на неё не влияет.
- Окно заранее показывает, подключена ли языковая модель; без неё кнопка запуска неактивна и объяснено, где взять готовые сценарии банка.
- Ход генерации (секунды) и отчёт — в окне; окно можно свернуть, задача продолжится. После завершения список переключается на категорию пачки, новые подсвечены и стоят вверху.
- Пометки в списке: «новый · на проверке» — сгенерировано и не подтверждено; «склейка · проверьте» — создано до 28.09 старой перестановкой билетов. Флажок «только новые, на проверке (N)».

### Бэкенд

- `GET /teacher/scenarios/generation-status` → `{generator: llm | none | recombination}`.

### Контракт

- `openapi.yaml` 0.3.12 → **0.3.13**: путь `/teacher/scenarios/generation-status`, схема `GenerationStatus`. Только добавление.

### Документация

- без изменений

## Почему так

- Новое определяется без новых полей: сгенерированный, неподтверждённый и не из поставляемого банка (`gen-seed-*`). Подтверждение эталона снимает пометку — ровно тот момент, когда сценарий перестаёт быть «на проверке».
- Старые сценарии перестановки (`gen-…`) помечены отдельно: это те несуразности, которые видел преподаватель, выдавать их за новые нельзя.

## Проверено

- Сборка образа бэкенда с тестами, `npm run lint`, стенд: статус отвечает `llm`, новый бандл отдаётся.

## Не сделано

- Удаление сценариев из интерфейса: 25 сценариев старой перестановки на стенде можно только подтвердить или поправить.

## Требует внимания

- Пометка опирается на префиксы id: `gen-seed-` — банк, `gen-` — старая перестановка, `custom-` — созданное после 28.09. Меняя схему id, поправить `isFreshGenerated` / `isOldRecombination` в `Scenarios.tsx`.
