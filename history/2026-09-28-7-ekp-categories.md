# 2026-09-28 — категории сценариев по разделам ЕКП

**Ветка:** `fix/ekp-categories`
**Коммит:** `—` (заполнить после коммита)
**Суть:** категория сценария теперь — позиция списка «Что случилось?», выведенная из раздела ЕКП, а не придуманная нами группа; частичный балл за тип дают только внутри этой позиции.

## Что сделано

### Фронтенд

- Подписи категорий — позиции «Что случилось?»: «Пожар (101)», «Правонарушение (102)», «Медпомощь (103)», «Газ (104)», «ДТП», «Человек в опасности», «Смертельный исход», «Аварии в городском хозяйстве», «Угроза обрушения», «Взрыв», «Угроза взрыва / теракта», «Животные».
- В карточке сценария категория не выбирается, а показывается: выводится из первого типа эталона.

### Бэкенд

- `ScenarioService.categoryFor`: категория сценария = категория главного (первого) типа; при сохранении присланное клиентом значение игнорируется.
- При старте категория пересчитывается у всей библиотеки, включая подтверждённые и созданные преподавателем сценарии (на стенде — 135).
- `CardFillAssessor`: частичный балл (0.5) — за тип из той же позиции «Что случилось?»; текст замечания говорит о разделе, а не о «категории».

### Контракт

- `openapi.yaml` 0.3.13 → **0.3.14**: у `Scenario.category` и `ScenarioListItem.category` описаны новые значения (id позиций из card-types). Тип поля прежний — строка, но **значения сменились**: клиенты, сравнивающие с FIRE / POLICE / MEDICAL, сломаются.

### Документация

- `tools/fix_scenarios.py`: таблица «раздел ЕКП → позиция» (24 раздела, для 7, 10, 11, 23 — по подразделу); категории пишутся в `seed/incident-types.json`.
- `scenario-overrides.json`: у билетов с дракой и травмами первым идёт «Драка» — правило главного типа.

## Почему так

- Прежние 7 категорий были ручными и делили по двум осям сразу: по службе (полиция, медицина, газ) и по характеру (пожары, спасение, ЖКХ). В ЕКП деление одно — раздел по номеру, и он совпадает с позицией, которую оператор выбирает первой (`docs/materials/card-types.md`).
- Категория участвует в оценке: частичный балл давался за «Драку» вместо ДТП (обе «полиция») и за «Травму» вместо попытки суицида, а правильный по ЕКП сосед «Человек в опасности» получал ноль.
- Основная служба в ЕКП зависит от ответов (попытка суицида — МЧС, с летальным исходом — МВД), поэтому категорией она быть не может.

Сдвиги по типам: попытка суицида и пропажа — «Человек в опасности» (раздел 17); обнаружен труп — «Смертельный исход» (19); угроза взрыва — «Угроза взрыва / теракта» (4); ДТП, включая падение в воду, — «ДТП» (2); дерево и люк — «Аварии в городском хозяйстве» (14).
